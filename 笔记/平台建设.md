# 平台建设

## 人机协同平台

| 能力 | 状态 |
| --- | --- |
| 人工创建工单并触发平台 | 已有 |
| 从 Git 拉代码、提供标准配置真机环境并交互验证 | 已有 |
| 错误分析、建议修法与合规检查 | 建设中 |

流程：本机开发并提交 Git → 人工创建工单 → 平台拉 Git 代码验证 → 给出分析和建议 → 开发者本机手动修复并提交。

平台不执行自动代码修复，不代替开发者提交代码。
