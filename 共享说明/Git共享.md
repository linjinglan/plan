# Git 共享

## 共享内容

共享整个演示库中的 Markdown 笔记、任务日期和依赖、CSS 样式、初始化脚本和插件版本锁定信息。每位成员使用自己的 Obsidian 打开拉取后的目录。

不共享窗口布局、缓存、个人快捷键、插件运行文件或验证截图。插件代码由初始化脚本按锁定地址下载并核对 SHA-256。

## 当前状态

共享远程仓库：https://github.com/linjinglan/plan.git 。本机 Obsidian 仓库目录：`G:\AIProjects\plan`。

本目录可以作为独立 Git 仓库的根目录。实际分支、提交和同步状态以 Git 命令输出为准；准备好文件不代表已经上传到远程。

将本目录放进专门的共享仓库，避免把父目录中的其他项目一起上传。创建分支和执行提交前，需要按你的 Git 规则确认完整分支名及完整提交信息。

## 日常协作方式

1. 编辑前拉取最新版本。
2. 修改 `任务/测试工作计划.md` 中的日期、状态或依赖，或修改说明笔记。
3. 检查差异，提交自己的更改，再推送。
4. 其他成员拉取后，Project Planner 根据相同文件重建视图。

Git 是异步共享。两人同时改同一行任务时，需要解决合并冲突，不提供多人光标或实时共同拖拽。

## 其他成员首次打开

运行 `初始化演示.ps1` 获取锁定的插件文件，再用 Obsidian 打开本目录，按界面提示确认是否信任并启用这两个插件。

脚本不会提交、推送、改写远程仓库，也不会改动任何已有笔记库。
