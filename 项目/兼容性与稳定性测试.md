# 兼容性与稳定性测试

## 案例开发（功能测试）

现有稳定性案例已在 Git，可直接复用。兼容性先评估 P0 案例，再复核已有案例、补齐缺口，开发者在本机手动修改并提交 Git。

## 人机协同平台

代码提交后，由人创建工单触发平台，平台从 Git 拉取代码，在标准配置真机环境运行，验证改动风险和影响面，并在多人合并主干时进行合规性检查。

平台只给出错误分析和建议修法，不自动修复代码、不自动提交。开发者依据建议在本机修复并手动提交，代码所有权清晰。

## 自动化平台与设备执行

Git 统一管理案例。稳定性和兼容性都在自动化平台触发，平台分发任务到 4 台负载机，再由负载机分发和控制港湾一号测试机。

## 结果验收

稳定性：全流程完成，无崩溃、内存泄漏或越玩越卡。自动化平台已有崩溃、内存及 FPS 校验能力。

兼容性：每一步操作都要校验是否有兼容问题，自动化平台需要提供校验方法。

已有的架构 HTML 继续保留在原工作目录，本库重点演示任务、日期和笔记联动。
